# RabbitControl Android 界面规范

首版采用原生控制工具的视觉风格。底部常驻设备、远程协助和我的三个入口。设备页显示账号设备与在线状态，远程协助页提供设备码确认、最近使用与收藏，我的页面管理服务器、账号和画面校验。首页跟随系统外观；进入画面页后，整块视口、系统栏和手势提示统一切换到固定深色。品牌蓝取自 [macOS 色板](../rabbitcontrol-macos/crates/rc-ui/ui/assets/css/tokens.css) 和 [管理后台色板](../rabbitcontrol-server/web/src/styles/global.css)。

探测进行时显示进度文字并禁用重复提交。成功显示服务器状态、探测耗时与指纹；异常显示原因，并恢复检测按钮。颜色只辅助识别，文字始终说明状态。颜色角色定义在 [浅色色板](../app/src/main/res/values/colors.xml) 和 [深色色板](../app/src/main/res/values-night/colors.xml)。

## 字体、尺寸与控件

- 使用 Android 系统无衬线字体及中文回退字体，随系统字号缩放。产品名 28sp，分组标题 22sp，正文与按钮 16sp，字段标签和辅助信息 14sp。标题与标签使用中等字重，解码器名称和帧率使用系统等宽字体。
- 按 4dp 为单位安排间距。手机首页左右留白 20dp，最小宽度达到 600dp 的设备留白 64dp。卡片间隔 16dp，内边距 20dp。内容可以纵向滚动，以容纳软键盘和大字号。
- 卡片用 16dp 圆角和 1dp 描边，输入框与按钮用 10dp 圆角。输入框保留可见标签，获得焦点时使用 2dp 强调色描边。按钮和输入框最小高度 48dp。
- 同一页只突出一个主要操作。一个表单使用一个实心主按钮，历史、收藏、刷新等辅助操作使用浅底按钮或列表行。禁用态和按压反馈使用统一颜色与原生 ripple。[组件样式](../app/src/main/res/values/styles.xml)

## 视频视口与操控

- 固定视口底色 `#07090D`，上下工具区底色 `#141920`，文字使用 `#F2F5FB` 和 `#B7C2D1`。状态与提示排在视频外，避免遮住远端按钮和文字。
- SurfaceView 等比居中；触控层和视频共享布局尺寸。画面外的黑边只补齐宽高比。轻点触发左键、长按触发右键、单指移动可拖动、双指滑动滚动。光标即时本地绘制。
- 页面主题只控制 Android 界面。解码线程直接向 Surface 提交画面，诊断数字按秒更新。系统外观切换和横竖屏切换后，画面页继续使用同一套固定深色资源。[画面页布局](../app/src/main/res/layout/preview.xml)

设备、远程协助与账号设置沿用 `AppTheme`；呈现远端桌面的页面使用 `SessionTheme`。技术栈、真会话接入条件与性能验收见 [架构设计](architecture.md)。
